What should this project folder contain?
Always required

Point to the project root, not a single file. It must contain the source code and any files needed to understand its dependencies.

Recommended

Keep the dependency manifest and lock file, such as requirements.txt, pyproject.toml, package.json, go.mod or pom.xml.

Include compose.yaml or docker-compose.yml. If it builds images, include the referenced Dockerfiles. The app must expose a local HTTP URL and a health path.

For deeper workflows

Add a Runtime Contract or configure test accounts and business workflows below. Do not commit passwords, API keys or real customer data.

07Reflected server-side cross-site scriptingmerged-ea527a7d7441e2b11700highconfirmed vulnerabilityblock⌄

Assessment

The `catalog_search` endpoint directly interpolates the user‑controlled query parameter `q` into an HTML response without any escaping or sanitisation. The returned string `<h1>Results for {q}</h1>` will render any HTML/JavaScript supplied in `q`, enabling a reflected XSS attack. Additionally, `q` is concatenated into a raw SQL statement, which could also lead to SQL injection, but the primary confirmed issue is the reflected XSS.

Impact

An attacker can craft a URL such as `/catalog/search?q=<script>maliciousCode()</script>` and trick a victim into visiting it. The injected script runs in the victim's browser context, allowing theft of session cookies, credential harvesting, defacement, or further malicious actions against the user or the application.

Remediation

* Use a proper templating engine (e.g., Jinja2) that automatically escapes variables. * Explicitly HTML‑escape the `q` value before embedding it in the response (e.g., `html.escape(q)`). * Switch to parameterised queries for the database call to prevent SQL injection. * Set a strict Content‑Security‑Policy header to mitigate script execution. * Consider returning JSON data and letting the client render it safely instead of raw HTML strings.

Evidence

  • Source excerpt lines 141‑145 show the endpoint definition and the direct insertion of `q` into the HTML response: `return f"<h1>Results for {q}</h1>" + "".join(f"<p>{row['name']}</p>" for row in rows)`
  • The SQL query also concatenates `q` without parameters: `SELECT name FROM products WHERE name ILIKE '%{q}%'`

Source IDs

  • merged-ea527a7d7441e2b11700

Limitations

  • No runtime execution was observed; the assessment is based solely on static code analysis. We assume FastAPI's `HTMLResponse` does not perform automatic HTML escaping, which is typical for raw string responses. Potential mitigations (e.g., upstream middleware sanitising inputs) were not identified in the provided code.
